# 3D model provenance

`z2-spacesuit.glb` — "Z2 Spacesuit", NASA's exploration suit prototype, from NASA 3D Resources
(https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Z2%20Spacesuit).
Downloaded 2026-11-14. Geometry, materials and WebP textures are unmodified; the duplicate JPEG
fallback textures were removed (16.5 MB -> 2 MB), so the file now requires WebP support
(EXT_texture_webp). The mesh is Draco-compressed; the decoder is served from `/draco/`.
NASA 3D Resources are free to use; see NASA's media usage guidelines.
